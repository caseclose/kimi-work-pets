Kimi Work Pets

把 Codex Pets 社区桌宠一键装进 Kimi Work 桌面端。14 款精选宠物,自带悬停互动、视线跟随转头,兼容 macOS 与 Windows。

打开 GitHub 仓库 浏览宠物画廊

Highlights

特性

⌘
一键安装一条命令完成转换与注入,自动备份原桌宠,可随时回滚。
✦
悬停互动鼠标悬停时宠物主动打招呼(Hiyuki 挥剑、Dimo 挥爪)。
◎
视线跟随宠物会根据鼠标位置转动头部,时刻「看」着你。
⧉
双平台支持 macOS 与 Windows,处理 Rive 动画与精灵表自动转换。

Get started

快速开始

  1. 克隆仓库:git clone https://github.com/caseclose/kimi-work-pets.git
  2. 安装宠物(以迪莫为例):python3 scripts/install.py pets/dimo
  3. 重启 Kimi 应用,桌面上就会出现新桌宠;悬停试试它的互动动作。

恢复默认桌宠:python3 scripts/restore.py(自动使用安装前的备份)。
