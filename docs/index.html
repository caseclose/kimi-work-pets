Overview

从社区画廊到桌面伙伴

Kimi Work 除默认 Rive 形象外，还支持与 Codex 同源的精灵表（8×9 网格、192×208 单元格）。本仓库补齐转换、安装、回滚与互动补丁。

1

取材社区

从 Codex Pets 画廊挑选形象。仓库已预置 14 款，也可自行下载任意社区包。

2

一键注入

install.py 负责转换清单、写入应用数据、备份原桌宠，失败可随时 restore。

3

桌面互动

安装即带悬停招手、视线跟随、拖动奔跑。重启 Kimi 后，桌宠会看向你。

Interactions

安装即用的四种互动

由三个幂等补丁自动注入，无需额外配置；restore.py 会一并撤销。

01

悬停招手

鼠标悬停时播放 idle_random_1 一个循环后回到待机，6 秒冷却，不影响工作或等待状态。Hiyuki 挥剑，Dimo 挥爪。

02

视线跟随

鼠标在附近移动时，精灵图宠物平滑向光标倾斜；离开后回正。Rive 默认形象自带眼动，补丁会自动跳过。

03

拖动奔跑

拖动桌宠时沿方向播放左右奔跑帧，这是 Kimi Work 的原生行为，安装后继续保留。

04

更大的响应范围

默认 2 倍显示；可点区域在轮廓外再扩 24px，不用对准像素。由页面主动上报可交互区域实现。

Install

三步装上桌宠

需要 Kimi Work 桌面端与 python3。Windows 按 Electron 惯例定位 %APPDATA%\kimi-desktop；找不到时加 --appdata。

  1. 克隆仓库
    git clone https://github.com/caseclose/kimi-work-pets.git
  2. 安装一只宠物（可换成 pets/ 下任意目录）
    python3 scripts/install.py pets/dimo
  3. 重启 Kimi，或重新开关桌宠。悬停试试招手，移动鼠标看它转头。

回滚与备份

原配置自动备份在用户目录 .kimi-work-pet-backup/。

python3 scripts/restore.py

平台说明

  • macOS：自动定位 Kimi 应用数据目录
  • Windows：路径按惯例推断，未经全面真机验证
  • 所有脚本都接受 --appdata <目录>

Bring your own pet

安装画廊里的其他宠物

社区包通常含 pet.json 与 spritesheet.webp。转换器会统计每行帧数，并把原清单备份为 pet.codex.json。

  1. 从 CodexPets.net 或 petdex.dev 下载并解压宠物包。
  2. 转换：
    python3 scripts/convert-codex-pet.py <目录>
  3. 安装：
    python3 scripts/install.py <目录>

布局不符时，用 scripts/inspect_spritesheet.py 逐行确认后再改 pet.json。机制说明见 桌宠机制调研。

FAQ

常见问题

装完没有变化？

完全退出并重启 Kimi Work，或先关掉再打开桌宠。渲染器只在加载时读取配置。

如何回到默认形象？

运行 python3 scripts/restore.py。脚本会使用安装前自动备份，并撤销互动补丁。

Windows 找不到目录？

手动指定应用数据目录：--appdata %APPDATA%\kimi-desktop。各脚本均支持该参数。

能装画廊里没预置的宠物吗？

可以。先 convert-codex-pet.py，再 install.py。标准 9 行精灵表即可自动映射。
